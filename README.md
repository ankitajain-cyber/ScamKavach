# 🛡️ ScamKavach
**AI-Driven Digital Safety, Threat Intelligence & Cyber Forensics Gateway**

ScamKavach bridges everyday consumer scam protection with forensic-grade digital evidence preservation. Built with Python and Streamlit, it analyzes suspicious SMS, email, and chat payloads using hybrid Explainable AI (XAI) heuristics to detect psychological manipulation, extract Indicators of Compromise (IOCs), and generate cryptographically verifiable incident reports.

### Key Capabilities
- **Hybrid Threat & Kill-Chain Analysis:** Evaluates single messages and multi-stage WhatsApp/Telegram social engineering progressions.
- **Automated IOC Extraction:** Isolates malicious URLs, phone numbers, UPI handles, and IP addresses via deterministic Regex rules.
- **Bilingual Explainable AI (English & Hindi):** Translates risk scores and manipulation triggers into plain, actionable guidance.
- **Forensic Evidence Preservation (SHA-256 + PDF):** Computes cryptographic payload hashes and packages findings into structured ReportLab PDF dossiers ready for cyber-crime reporting (e.g., Chakshu).
- **Live OSINT Threat Feeds:** Integrates real-time cyber advisory RSS feeds to track active fraud campaigns in India.
